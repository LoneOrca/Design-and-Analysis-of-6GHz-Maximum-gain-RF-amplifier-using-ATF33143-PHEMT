# 6 GHz Maximum Gain RF Amplifier Design using ATF-33143 PHEMT

## Overview

This project presents the analytical design of a 6 GHz maximum-gain RF amplifier using the ATF-33143 PHEMT transistor.

The work focuses on:

* Stability analysis
* Reflection coefficient calculations
* Gain calculations
* Smith chart-based impedance matching
* Input Matching Network (IMN)
* Output Matching Network (OMN)

---

## Design Specifications

* Frequency: 6 GHz
* Device: ATF-33143 PHEMT
* Bias Condition:

  * VDS = 4 V
  * IDS = 80 mA

---

## Design Procedure

1. Stability Analysis
2. Calculation of Reflection Coefficients
3. Gain Calculations
4. Input Matching Network Design (IMN)
5. Output Matching Network Design (OMN)
6. Smith Chart Analysis
